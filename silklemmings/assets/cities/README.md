- changan.png：長安，中國宮殿。
- yumenguan.png：玉門關，中國城門。
- yuezhi.png：大月氏，中東建築意象。
- daqin.png：大秦，羅馬凱旋門。

city-landmarks.js 依各關路線排列背景地標，返程調整位置，文字不鏡像。地標不參與碰撞、傷害或點擊。原始生成提示詞如下。
