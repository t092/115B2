# 絲路小商人

獨立、繁體中文、卡通風格的商隊策略遊戲。主檔 `index.html` 可直接由瀏覽器開啟，不需要安裝、伺服器、登入或網路；只有史實手記中的延伸閱讀需要網路。尚未連接專案主頁。

## 閱讀介面

主文與操作文字放大至 17–18 px，輔助標示以 14–15 px 起跳；地圖文字依畫布顯示寬度調整，避免手機縮放後過小。

## 操作

1. 閱讀劇情，在右側為每一位夥伴選擇馬或駱駝、貨物及數量。手機版配貨面板位於地圖下方。
2. 馬最多載 5 單位，速度 88；駱駝最多載 1 單位，速度 45。速度單位為遊戲座標／秒，並非歷史測量。
3. **生命與裝備**：駱駝基礎生命 100、馬 60。浮沙踏板對應流沙，防風罩對應龍捲風，引仇盾額外增加目前與最大生命各 500（駱駝 600、馬 560）。每隻駱駝只能攜帶一種道具，裝上第一種後其餘裝備按鈕鎖定；馬維持原有配裝規則。同一道具不可重複加成。裝備者不能載任何貨物；載貨者不能裝備。裝備鎖定不可卸下，連同動物死亡時消失。配貨階段也不能替已裝備者改種類或移除，道具免費。
4. **先駐守、後放行**：預設每個危險點都有一隻只帶對應道具的駱駝負責，另有載貨駱駝，最多 12 隻。按「整裝出發」後，守護駱駝先走，載貨者在起點待命。駱駝可依指令到指定點自動停下；有駐守任務者會穿過中繼點。可直接按「貨隊出發」，或點個別待命夥伴出發。駱駝在未受保護且自身無對應道具的陷阱前 8 座標處自動等待，守護者到位後自動繼續；這是停在危險範圍外，不是碰到陷阱免死。若駐守者死亡，路徑上其他駱駝會繼續等待，需要重新安排守護。不要等全線到位才放行，以免前段守護者先耗盡生命。馬一旦上路，只有中繼點能停；抵達中繼點需放行。
5. **陷阱傷害**：陷阱範圍為中心前後 36 遊戲座標。未攜帶對應道具、也無駐守保護者，接觸流沙或龍捲風立即死亡。攜帶對應道具者在流沙每秒扣 2、龍捲風每秒扣 5，移動或停下都會受傷。龍捲風持續有效，不再有舊版平息免傷時段。只有「停在該陷阱內且帶對應道具」的存活駱駝可讓其他未裝備夥伴無傷通過；移動中的馬或駱駝不能提供群體保護。守護者即使被另一隻駱駝覆蓋，也照常承受自身傷害。守護者死亡、離開或繼續移動，保護立即消失。
6. **弓箭手**：原地不動，射程為前後 260 座標，每秒一箭，傷害 10。第一次找到目標立即射擊，之後間隔一秒。優先選射程內存活、尚未抵達的持盾動物；同優先級選距離最近者。射程外的盾無法吸引攻擊；目標死亡後會重新選擇。盾不是無敵，也不能替代陷阱所需的對應道具。箭矢扣生命，死亡才失去全部貨物與道具。
7. **途中操作**：選道具後點地圖夥伴，或用卡片上的裝備按鈕，只有空載者能補裝。馬保持行進；停下的駱駝保持停下。點駱駝編號可停走；卡片下拉選單可指定前方駐守點。選「手動停走」只取消自動駐守指令，繼續前進仍需點編號。血條與生命數字會持續更新。
8. 暫停、兩倍速、視野滑桿與跟隨商隊均可使用。鍵盤空白鍵暫停，1／2／3 選道具；表單操作時不攔截快捷鍵。暫停、劇情視窗或切到其他分頁時停止移動與傷害；兩倍速同時加速移動和傷害時鐘。
9. 載貨隊全數死亡即失敗，可回到本趟出發前恢復資金。載貨隊皆抵達或死亡，且至少一隻抵達，就結算；不必讓仍駐守的支援隊跑到終點。第一章被俘事件優先處理，仍非 game over。

## 四章

| 章節 | 路線與事件 |
| --- | --- |
| 出使西域 | 長安 → 玉門關 → 大月氏（目標）。離開玉門關後，領隊抵達被俘位置即觸發全隊被俘，按當下所有存活夥伴的剩餘絲綢出售。不會 game over。 |
| 張騫出逃 | 匈奴據點 → 大月氏。可重新買絲，加入弓箭手與陷阱。 |
| 返回漢朝 | 大月氏 → 玉門關 → 長安。購買胡瓜、葡萄、笛、琵琶。 |
| 建立絲路 | 長安 → 玉門關 → 大月氏 → 安息 → 大秦，再沿原路回長安。西行只帶絲，東歸只帶葡萄／琵琶。 |

抵達後自動出售存留貨物，下一趟再配貨。動物由商團提供，不收租金。第四章起始資金作為基準，貨款即時扣除、收入抵達結算；回到長安時淨獲利達 10,000 元通關。援助款同步提高基準，不會算作獲利。通關後可自由貿易。

| 商品 | 買入單價 | 售出單價 |
| --- | ---: | ---: |
| 絲綢 | 30 | 100 |
| 胡瓜 | 40 | 130 |
| 葡萄 | 65 | 200 |
| 笛 | 90 | 280 |

所有金額、容量、速度、工具與戰鬥數值均是遊戲設定。

## 進度

localStorage 使用 `silklemmings-v1`。每完成一趟、確認進入下一趟時存檔；途中重新整理會回到該趟準備階段，不儲存每個行進座標。瀏覽器封鎖儲存時仍可玩，但無法保留跨次進度。重玩按鈕會要求確認。

## 教材與歷史界線

依據使用者提供的 `G2B3L21/B3L21.pdf`（視覺確認第 2、4、5 頁）及 `G2B3L21/B3L21_教師備課.md`，並查核以下資料（2026-09-23）：

- [ChinaCulture：Zhang Qian](https://en.chinaculture.org/gb/en_aboutchina/2003-09/24/content_22624.htm)：西行、被拘留及逃出。
- [UNESCO：About the Silk Roads](https://www.unesco.org/en/silk-roads/about-silk-roads)：絲路是路線網絡，商隊常分段貿易。
- [UNESCO：Main Street of Eurasia](https://en.unesco.org/silkroad/content/main-street-eurasia)：漢、唐及中介商人的長期角色。
- [文史廣東：玉門關的千年變遷](https://www.gdwsw.gov.cn/wsbl/content/post_38154.html)：設關年代晚於張騫首次出使，年代與關址仍有討論。

史實與改編在章節劇情及「史實手記」中明示：

- 張騫出使的原始目的是結盟抗匈奴，非為開店；被拘留、逃出及大月氏不願結盟是史實脈絡。
- 「佩服勇氣而交易」沒有作為歷史事實呈現；首次出使使用玉門關為路標，是後世地標投射。
- 第四章由後世商隊接棒，並非張騫活到唐代；大秦與匈奴造型為沿用的跨時代遊戲元素，未將其解釋成唐代的實際同時存在政權。
- 中國與羅馬之間通常有中介商人；單一商隊直達大秦再回來，是玩法簡化。
- 胡瓜、葡萄、笛、琵琶代表西域交流，未宣稱皆由張騫親自帶回，也未宣稱回程物品都原產羅馬。
- 使用者第三章「枇杷」依教材及第四章脈絡，先採樂器「琵琶」。

## 檔案與驗證

- `index.html`、`style.css`、`equipment.css`、`readability.css`、`game.js`：完整遊戲，所有插圖以 Canvas 向量繪製。
- `source-extract.txt`、`source-page2.png`、`source-page4.png`、`source-page5.png`：教材閱讀中間檔；遊戲執行不會載入。
- `tests/playthrough.cjs`：執行 `trade-and-defense.cjs`，使用單裝備預設隊形讓駱駝實際走到駐守位置、貨隊同步出發並在危險範圍外等待，經四章與往返獲利通關，未跳過陷阱或提高生命；亦驗證結算、重試、存檔與手機版面。
- `tests/equipment.cjs`：執行 `combat.cjs`，驗證生命／傷害數值、立即死亡、停駐保護、逐秒傷害、傷害不依畫面幀率改變、死亡移除裝備與保護、裝備和貨物互斥、駱駝單裝備限制、非法多裝備出發阻擋、引仇盾生命及射程內優先選敵、重選目標與 UI 鎖定。
- `tests/combat-results.json`：本版戰鬥規則檢查結果；`combat-desktop.png`、`combat-mobile.png` 為本版畫面。早期 `equipment-*.png` 與 `equipment-results.json` 留作前版驗證紀錄，不代表目前規則。
- `tests/results.json`、`tests/*.png`：實測報告與桌面、手機、被俘、通關截圖。

在專案根目錄執行 `node silklemmings/tests/playthrough.cjs`。測試需既有 Playwright 與 Microsoft Edge；遊戲本身不需要這些依賴。測試專用介面僅在網址帶 `?test` 時啟用。
