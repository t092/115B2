# 時序藏書室視覺更新

主遊戲使用暖紙、墨褐棋盤、低飽和銘牌與四方向小書吏。隱藏關使用深靛青藏書閣主題、剩餘時間進度條、靜態選取框與結算獎勵卡。

- `dynasty-theme.css` 集中管理主遊戲與隱藏關外觀。
- 人物在地板格內以獨立圖層呈現，站在目標時保留目標標記。
- 字體、銘牌大小及跨格提示沿用 HTML 結構，未把朝代文字畫入圖片。
- 小螢幕保留可讀格寬，棋盤容器可橫向捲動，附方向按鈕。
- 觸控裝置（含平板與橫向手機）使用底部固定方向列，棋盤可上下／左右拖曳，移動時自動保持人物可見；低高度橫向畫面縮小標題區，避免控制列遮擋人物。
- 隱藏關支援點兩個相鄰銘牌或短滑動交換；每次手勢只處理一次，取消觸控不交換，鍵盤仍可操作。
- 尊重系統減少動態效果設定；思考時人物靜止。
- 隱藏關結束先保留結果於 sessionStorage，再由「查看本次總成績」返回既有結算流程。
- Firebase 設定、計分公式、關卡配置與解鎖門檻未變動。

驗證：`npm test`；`node DynaSoKOBAN/tests/visual-browser.cjs`。後者以離線測試資料驗證五關字體尺寸、精靈載入、推動、到位、手機版容器、隱藏關倒數與獎勵卡，截圖輸出到 `test-results/dynasty-visual/`。不會提交正式 Firebase 成績。

觸控回歸：`node DynaSoKOBAN/tests/touch-browser.cjs`。Chromium 真正的觸控事件模擬 390×844、844×390、820×1180、1180×820，檢查方向按鈕點擊、推動、人物未被控制列遮擋、點選交換、短滑動、垂直滑動與 pointercancel。此為瀏覽器模擬，不代表已在 iOS Safari 實機驗證。
