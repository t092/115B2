# 小書吏精靈圖

Generated with the built-in ImageGen tool, then processed with generate2dsprite for shared scale, feet alignment, transparency and frame QC.

Runtime asset: `sheet-transparent.png`, 320 × 256, 5 columns × 4 rows, 64 px per frame. Rows: down, left, right, up. Columns: idle, walk A, walk B, push A, push B. Raw source, individual frames and processing metadata are retained for future revisions. The game renders the sprite at 56 px, including its transparent margins.

No scoring, dynasty sequence or collision data is encoded in the artwork.
